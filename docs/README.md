# Documentation

This directory records the relationship between the earlier project organization and the Exp1–Exp6 order used in the current manuscript, exclusion criteria, restricted materials, ethics and preregistration references, and release records.

- `experiment_renumbering.csv`: old-to-new experiment mapping.
- `exclusion_criteria.md`: participant exclusion rules and final included samples.
- `stimulus_availability.md`: materials withheld because they are third-party or face-derived.
- `preregistration_and_ethics_links.md`: retained study-registration and ethics information.
- `BUILD_PROVENANCE.md`: how this public-release candidate was assembled without modifying project sources.
- `release_checklist.md`: remaining checks before the GitHub repository becomes public.
