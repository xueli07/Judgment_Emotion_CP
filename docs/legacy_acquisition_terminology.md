# Legacy acquisition terminology

The revised manuscript uses **judgment phase** for the repeated task in Exp1 and Exp2. The public processed data, analysis code, repository documentation, and experiment numbering follow that terminology.

Some raw PsychoPy columns and PsychoPy condition-workbook filenames still contain `training` or `identification`. They are retained only where changing an acquisition-time name would break a reference inside a formal PsychoPy program or obscure the link to the recorded raw export. They do not describe an additional training intervention. The raw-data README and column dictionaries identify the public interpretation of these fields.
