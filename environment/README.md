# Software environment

The original analyses used Windows 11 and R 4.5.0. Exp6 used MATLAB R2023b with Image Processing Toolbox and the bundled Stat4CI source. HDDM ran in `hcp4715/hddm:1.0.1` with Python 3.9.13 and HDDM 1.0.1.

Data acquisition used PsychoPy 2024.2.4 for Exp1, Exp2 and Exp6, and PsychoPy 2023.2.3 for Exp3–5.

See the [analysis guide](../code/analysis/README.md) for dependencies and the [runtime table](../README.md#outputs-and-runtime) for estimated runtimes.

See [software versions](software_versions.csv) and [reproduction notes](REPRODUCIBILITY.md) for version records and session information.
