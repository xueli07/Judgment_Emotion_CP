# Experiment programs and condition workbooks

This directory contains PsychoPy Builder files (`.psyexp`), generated Python files, and condition workbooks for Exp1–Exp6. A/B and AB/BA suffixes identify counterbalancing variants.

The public repository intentionally omits TFED face images, morphed faces, average faces, noise faces, and face-derived classification images. Consequently, these programs document the experimental procedures but cannot run end-to-end without authorized local assets and path relinking.

Some internal filenames retain `training` or `identification` because changing them would break references embedded in PsychoPy programs. The current manuscript calls these tasks the judgment phase.
