# Acquisition-column dictionaries

These dictionaries preserve definitions of historical acquisition fields; original participant exports and participant-inclusion tables are not distributed. They are supplementary documentation, not the schema of every processed CSV. Use the supplied processed CSV headers and the [own-data guide](../../code/analysis/README.md#using-the-code-with-your-own-data) when adapting data. In Exp1–2, legacy training/identification terminology refers to the judgment phase.
