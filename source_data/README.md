# Figure source-data index

`SOURCE_DATA_INDEX.csv` maps every main and supplementary figure to the processed data, analysis code, and available reference outputs that support it. Quantitative panels can be reconstructed from the complete processed trial-level tables supplied in `data/processed/`; the repository therefore does not duplicate those observations into a separate table for every panel.

Procedure schematics and the theoretical illustration do not require empirical source data. The index was checked against the revised manuscript dated 18 September 2026 and the final-figure deck dated 17 September 2026. The working PowerPoint and figure PDFs are not included because some contain obsolete terminology or restricted face imagery.
