# Software environment

`software_versions.csv` records versions recoverable from the manuscript and retained project materials.

The manuscript reports R 4.5.0 for Exp1–Exp2 and R 4.3.3 for Exp3–Exp5. The HDDM environment used Python 3.9.13 and HDDM 1.0.1. Exp3 and Exp6 release-table exports were run in local R 4.5.0; their `sessionInfo()` files are saved with the corresponding reference outputs. The available MATLAB executable reports version 23.2.0.2344743 (R2023b), but this does not by itself prove it was the version used for the original Exp6 analysis. The bundled Stat4CI source has no version tag; its source header cites 20 August 2004. Before publication, run the complete analyses in a clean environment and add a verified R lock file where possible.
