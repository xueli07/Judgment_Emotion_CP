# Experiment 3 reference outputs

`03_export_reference_outputs.R` regenerates these numerical tables from the released trial-level data using the original model forms and centered morph scale:

- `AIC_model_comparison.csv` and `AIC_best_model_by_condition.csv`: group-level logistic, linear, and step-model comparisons.
- `psychometric_parameters_by_participant.csv`: participant-level PSE and slope estimates.
- `PSE_slope_paired_tests.csv`: paired continuous-versus-categorical PSE and slope tests.
- `sessionInfo_exp03.txt`: the R session used for this release-table export.
