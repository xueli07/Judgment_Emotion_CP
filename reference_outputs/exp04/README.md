# Experiment 4 reference outputs

- `AIC_model_comparison_all_conditions.csv` and `AIC_best_model_each_condition.csv` contain the group-level model comparison.
- `psychometric_parameters_by_participant.csv` contains participant-level PSE and slope estimates used for the repeated-measures analyses.
- `anova_pse.html` and `anova_slope.html` are the original formal ANOVA reports. They were generated as HTML tables by the analysis package and renamed from their misleading `.doc` filenames without changing their contents.

These files originate from the archived `Analysis/study2` workflow, which corresponds to Experiment 4 in the current manuscript.
